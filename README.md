* Ot (QML, Qt Quick)

* CMake

---

### Описание

Реализованная функциональность:
- [x] Ввод чисел (включая десятичные значения)
- [x] Ввод арифметических операторов (+, −, ×, ÷, %)
- [x] Поддержка скобок первого уровня (без вложенности)
- [x] Очистка текущего ввода и результата
- [x] UI полностью реализован на QML (Qt Quick)
- [x] Изменение цвета системного status bar через C++ 
- [x] Реализация полноценного парсера выражений
- [x] Добавление скрытого меню 

> [!NOTE]
> Чтобы открыть скрытое меню:
> 1. Зажмите кнопку '=' на 4 секунды
> 2. Введите число 123 в течение 5 секунд 
> 3. Откроется скрытое меню
